# dotfiles

Personal dotfiles and tooling.

## dnvim — portable Neovim

Run Neovim anywhere with Docker:

```bash
dnvim README.md
```

**New machine?** See **[SETUP.md](SETUP.md)** for full install instructions.

Docker image: [`angeljuarez77/dnvim`](https://hub.docker.com/r/angeljuarez77/dnvim)

## Other manually installed dependencies

- [nvm](https://github.com/nvm-sh/nvm)
- [rust](https://www.rust-lang.org/learn/get-started)
- [zplug](https://github.com/zplug/zplug)
